# AI4HEOR 科研基础能力验收清单

**基线版本：** 0.1.43

**核对日期：** 2026-07-20

**适用范围：** 人类研究者主导的药物经济学与 HEOR 科研工作台

本清单只回答一个问题：即使不调用任何 HEOR 专属计算方法，AI4HEOR 是否已具备支撑日常科研项目的基础能力。

状态口径：

- **已交付**：当前 0.1.43 源码中有可执行路径和自动化验证；是否进入最终验收包以该包的独立验证记录为准。
- **部分交付**：已能完成部分工作，但明确列出了不能宣称的能力。
- **待建设**：不用预览器、模型自由生成或开发者 Codex Skill 冒充平台产品能力。

## 与 HEOR 专属能力的边界

通用科研能力只处理项目、证据、数据、代码、文档、图表、幻灯和溯源。它们不能因为“会写报告”或“会生成表格”就获得下列权力：

- 替研究者选择模型结构、参数、证据或方法；
- 将模型输出表述为成本效果、报销、定价或政策结论；
- 替代科学、方法、数据权利、外部使用或发布审批。

## 建议的下一阶段建设顺序

1. **第一方 DOCX/PDF 报告导出**：将已验证的结构化 HEOR 报告渲染为可交付文档，不使用已排除的外部源码。
2. **第一方 XLSX 结果表导出**：绑定当前输入、结果、单位、年份、币种与溯源记录。
3. **概念模型/研究路径图渲染**：从当前 `heor-model-design` 工件确定性生成可编辑、可导出的图。

以上三项是产品能力建设，不依赖开发者本机的 Codex Skill，也不通过放宽第三方准入规则获得。
