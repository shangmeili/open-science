# AI4HEOR 科研基础能力验收清单

**基线版本：** 0.1.45 源码候选

**核对日期：** 2026-07-20

**适用范围：** 人类研究者主导的药物经济学与 HEOR 科研工作台

本清单只回答一个问题：即使不调用任何 HEOR 专属计算方法，AI4HEOR 是否已具备支撑日常科研项目的基础能力。

状态口径：

- **已交付**：当前源码中有可执行路径和自动化验证；是否进入最终验收包以该包的独立验证记录为准。
- **部分交付**：已能完成部分工作，但明确列出了不能宣称的能力。
- **待建设**：不用预览器、模型自由生成或开发者 Codex Skill 冒充平台产品能力。

## 与 HEOR 专属能力的边界

通用科研能力只处理项目、证据、数据、代码、文档、图表、幻灯和溯源。它们不能因为“会写报告”或“会生成表格”就获得下列权力：

- 替研究者选择模型结构、参数、证据或方法；
- 将模型输出表述为成本效果、报销、定价或政策结论；
- 替代科学、方法、数据权利、外部使用或发布审批。

## 建议的下一阶段建设顺序

1. **概念模型/研究路径图渲染**：从当前 `heor-model-design` 工件确定性生成可编辑、可导出的图。
2. **引用样式与期刊格式**：在保留来源和字段冲突的前提下增加受控 CSL 样式渲染。
3. **可配置研究表格模板**：在已交付 HEOR 报告结果工作簿之外，逐项定义并验证其他科研表格的来源、字段与复核边界。

以上三项是产品能力建设，不依赖开发者本机的 Codex Skill，也不通过放宽第三方准入规则获得。已交付的 DOCX/PDF/XLSX 路径同样由应用原生代码执行，不依赖 Codex 文档或表格 Skill。
