# 药物经济学本地知识库

这是一个面向“学会基础理论，并能完成真实工作”的小型知识库。它不是资料仓库，而是把决策问题、方法、交付物和来源连起来的工作台。

## 从这里开始

1. 先看 [[00-导航/知识地图]]，建立全局框架。
2. 按 [[00-导航/8周学习路线]] 学习，每周完成一个可验证产出。
3. 做项目时从 [[03-工作实务/项目全流程]] 倒推，不要先选模型。
4. 查概念用 [[00-导航/术语表]]；查权威依据用 [[06-来源/权威来源索引]]。
5. 了解截至 2026-07-14 的变化，看 [[04-最新进展/截至2026-07的方法学与政策进展]]。

## 知识库边界

- **药物经济学**：比较备选干预的成本与健康后果，服务于资源配置决策。
- **HEOR**：比药物经济学更宽，还包括患者结局、真实世界研究、证据合成等。
- **HTA**：比经济性评价更宽，综合临床、经济、伦理、组织与社会影响。
- **不做的事**：不把某国阈值直接套到中国，不把报告规范当方法质量评分，不把“统计学显著”当“值得支付”。

## 目录

- `00-导航`：知识地图、学习路线、术语
- `01-基础理论`：稀缺性、评价类型、QALY、ICER
- `02-方法学`：决策问题、成本效果模型、证据、成本、效用、不确定性、预算影响
- `03-工作实务`：岗位内容、项目流程、质量门槛
- `04-最新进展`：有日期和状态标记的动态资料
- `05-模板`：可直接复制使用的研究与审查模板
- `06-来源`：权威入口、更新规则、更新日志

## 内容状态约定

- `稳定`：基础概念或已正式发布的方法指南。
- `现行`：截至更新日，机构网站显示为当前方法或政策。
- `草案`：征求意见或尚未最终实施，不能写成硬性要求。
- `新兴`：已有研究或实践，但尚无稳定共识。
- `历史`：仍有学习价值，但不代表当前要求。

## 使用原则

每个结论至少回答三个问题：它服务哪个决策者？适用哪个地区与时间？证据或假设是什么？如果答不出，不进入基础分析。
