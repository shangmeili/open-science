# 知识地图

药物经济学的核心不是“算 ICER”，而是在预算约束下比较备选行动，并把不确定性说清楚。

```mermaid
flowchart LR
  A["决策问题<br/>谁在什么场景决定什么"] --> B["比较方案<br/>目标人群与对照"]
  B --> C["证据<br/>效果 安全 效用 成本"]
  C --> D["分析<br/>试验内或决策模型"]
  D --> E["结果<br/>增量成本 增量健康 NMB"]
  E --> F["不确定性<br/>参数 结构 方法 异质性"]
  F --> G["决策支持<br/>价值 预算 公平 可实施性"]
```

## 三个必须分开的判断

1. **有效吗？** 临床证据回答相对疗效与安全性。
2. **值吗？** 经济评价回答相对于备选方案，新增健康是否值得新增机会成本。
3. **付得起吗？** 预算影响回答特定预算期内的现金流压力。

“成本效果好”不等于“预算影响小”；“临床有效”也不自动等于“具有成本效果”。

## 最小能力闭环

学完后应能独立完成：写一页决策问题 → 画疾病/治疗路径 → 建一个透明的简化模型 → 计算增量结果 → 做确定性与概率敏感性分析 → 写出边界明确的结论。
