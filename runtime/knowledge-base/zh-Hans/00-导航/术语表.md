# 术语表

| 术语 | 简明定义 | 易错点 |
|---|---|---|
| CEA | 以自然健康单位表示效果的成本效果分析 | 不同疾病、不同效果单位通常不可横向比较 |
| CUA | 以 QALY 等效用单位表示结果的成本效用分析 | 仍是一类 CEA，不等于“只看生活质量” |
| CBA | 将成本和收益都货币化的成本效益分析 | 健康货币化方法和伦理假设需透明 |
| CMA | 结果被充分证明等效后只比较成本 | “差异不显著”不能证明等效 |
| CCA | 分项列出成本和多种结果 | 透明，但不会自动给出单一决策规则 |
| QALY | 生存时间与健康效用的乘积；1 年完全健康约为 1 QALY | 效用权重来自偏好测量，不是临床评分本身 |
| ICER | 增量成本 ÷ 增量效果 | 比值在效果接近 0 或跨象限时难解释 |
| NMB | λ×增量效果−增量成本 | NMB > 0 表示在给定 λ 下具有成本效果 |
| WTP 阈值 λ | 决策者对额外一单位健康结果的最大可接受机会成本 | 不是药品价格，也不是跨地区通用常数 |
| 支配 | 新方案成本更高且效果更差，或成本更低且效果更好 | 多方案比较还要检查扩展支配 |
| 参考案例 | 为可比性预先规定的一组首选方法 | 偏离可以做，但需说明并另报情景 |
| 视角 | 决定纳入哪些成本与结果的决策立场 | 支付方、卫生体系、全社会角度不可混用 |
| 贴现 | 把未来成本和健康结果换算为当前价值 | CEA 与 BIA 的处理通常不同；按当地指南 |
| PSA | 给参数分配概率分布并传播不确定性 | 不是给单个 ICER 算普通置信区间 |
| CEAC | 不同阈值下某方案具有成本效果的概率 | 不是该方案“正确”的概率 |
| EVPI | 完全消除当前决策不确定性的期望价值上限 | 要结合受影响人群和技术寿命 |
| BIA | 估计新技术准入对预算持有者现金流的影响 | 不是 CEA 的简化版，也不以 QALY 为核心 |
| RWD / RWE | 真实世界数据 / 由其经恰当设计分析生成的证据 | 数据本身不等于证据；混杂与适用性是核心 |
| HTA | 对技术的临床、经济及其他影响进行系统评价 | 经济评价只是 HTA 的一部分 |
| HEOR | 卫生经济与结局研究 | 范围通常宽于药物经济学 |
| DCEA | 分布式成本效果分析，显式分析不同群体的健康分布 | 公平权重和社会价值判断必须单独说明 |
