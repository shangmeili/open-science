# 药物经济学项目全流程

## 阶段与验证门

| 阶段 | 最小行动 | 验证门 |
|---|---|---|
| 1. 决策对齐 | 写 1 页决策问题与预期用途 | 决策者确认人群、对照、视角、交付时间 |
| 2. 概念模型 | 画疾病/治疗路径和因果结构 | 临床、方法和患者视角完成表面效度审查 |
| 3. 分析计划 | 冻结基础分析、情景和验证方案 | 在看最终结果前签署版本 |
| 4. 证据获取 | 建参数清单和检索/数据计划 | 每个关键参数有来源、选择理由和备选值 |
| 5. 实现 | 先做最小可运行模型，再逐项增加 | 极端值、单位、守恒、手算对照通过 |
| 6. 不确定性 | 做 DSA、PSA、结构与方法情景 | 能指出会改变决策的变量和假设 |
| 7. 独立验证 | 由非开发者复核结构、公式与结果 | 问题清单关闭或保留并说明风险 |
| 8. 报告交付 | 同时交模型、说明、参数表、报告 | 数字跨文件一致，结论回答原决策问题 |
| 9. 生命周期更新 | 记录触发更新的证据或政策事件 | 版本、变更原因和结果影响可追踪 |

## 文件最小集

- 研究方案/健康经济分析计划
- 概念模型与假设登记表
- 参数来源表和证据选择日志
- 可运行模型与版本说明
- 验证记录
- 技术报告与决策摘要
- 利益冲突、资助和作者贡献声明

## 停止规则

如果对照不符合真实实践、关键结构未验证、模型无法复算、主要结论只靠一个无依据假设、或数据使用不合规，不应进入正式决策交付。

## 报告结论模板

“在【地区/视角/时限】下，与【对照】相比，【干预】预计增加【ΔE】并增加/节省【ΔC】；在阈值【λ】下 INMB 为【值】。结论最受【参数/结构】影响；在【情景】下会改变。预算影响为【逐年范围】。未纳入/尚不确定的主要影响是【内容】。”
