# QALY、ICER 与净货币获益

## QALY

若一个健康状态的效用为 `u`，持续 `t` 年，则 `QALY = u × t`。实际模型会按周期累计，并处理状态变化、死亡和贴现。

## 增量结果

设新方案为 1，对照为 0：

```text
ΔC = C1 − C0
ΔE = E1 − E0
ICER = ΔC / ΔE
```

| ΔC | ΔE | 初步解释 |
|---|---|---|
| < 0 | > 0 | 新方案绝对优势 |
| > 0 | < 0 | 新方案绝对劣势 |
| > 0 | > 0 | 以阈值判断新增健康是否值得新增成本 |
| < 0 | < 0 | 以阈值判断节省成本是否值得损失健康 |

多方案比较时，先按效果排序，排除绝对支配和扩展支配，再计算相邻有效前沿上的 ICER。

## NMB 更适合计算与不确定性分析

```text
增量净货币获益 INMB = λ × ΔE − ΔC
```

给定阈值 `λ`，INMB > 0 表示新方案具有正的净货币获益。NMB 避开 ICER 的比值不连续问题，更适合回归、PSA 和价值信息分析。

## 阈值不能偷换

《中国药物经济学评价指南2020》建议在 QALY 增量分析中采用全国人均 GDP 的 1–3 倍作为意愿支付阈值。它是团体指南中的方法建议，**不等同于国家医保谈判的公开定价公式，也不应被写成所有中国决策的法定阈值**。项目应说明阈值来源，并做范围分析。

## 微型例子

新方案多花 60,000 元，增加 0.5 QALY，则 ICER = 120,000 元/QALY。若 λ = 150,000 元/QALY，INMB = 15,000 元；若 λ = 100,000 元/QALY，INMB = −10,000 元。结论随决策阈值改变。
