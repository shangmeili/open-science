# 经济评价文献批判性评价模板

## 1. 决策相关性

- 研究问题、目标决策者和使用场景是什么？
- 人群、干预、对照、视角、时限是否适合我的问题？
- 研究是否比较了现实中的相关备选方案？

## 2. 临床与模型可信度

- 相对效果来源及偏倚风险？
- 短期证据如何外推到长期？
- 模型结构是否反映疾病和治疗机制？
- 假设是否透明并经验证？

## 3. 成本与健康结果

- 成本范围是否与视角一致？数量与单价是否分开？
- 价格年、贴现和本土化是否合理？
- 效用量表、价值集和人群是否匹配？
- 是否有重复计算或遗漏重要结果？

## 4. 分析与不确定性

- 是否正确处理支配和增量分析？
- 是否报告 DSA、PSA、结构与方法情景？
- 相关参数是否联合处理？
- 哪个假设或参数会改变结论？

## 5. 可迁移性与决策结论

- 哪些输入可迁移，哪些必须本土化？
- 研究阈值是否适用于我的决策环境？
- 资助、利益冲突和模型访问限制会带来什么风险？
- 最终判断：可直接采用 / 可经调整采用 / 仅作背景 / 不可采用。
- 改变判断所需的最小新增证据：

> CHEERS 可辅助检查报告是否完整，但不要把勾选数量当方法质量分。
