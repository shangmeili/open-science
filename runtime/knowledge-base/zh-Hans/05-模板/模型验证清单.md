# 模型验证清单

## 概念与表面效度

- [ ] 结构对应疾病自然史、治疗路径和干预机制
- [ ] 目标人群、对照、视角和时限与方案一致
- [ ] 临床、患者/照护者和方法专家意见已记录
- [ ] 排除的事件和后果有明确理由

## 内部与技术验证

- [ ] 单位、周期、率/概率转换正确
- [ ] 概率边界与状态人数守恒正确
- [ ] 死亡和吸收状态处理正确
- [ ] 成本、效用和事件无重复累计
- [ ] 贴现时点正确
- [ ] 极端值、零效应、相同方案测试通过
- [ ] 手算或独立实现复核关键公式
- [ ] PSA 分布、相关性、迭代误差检查完成

## 外部与交叉验证

- [ ] 基线事件、生存和成本与外部数据比较
- [ ] 与已发表模型的结构和结果差异有解释
- [ ] 长期预测符合临床与一般人群边界
- [ ] 有后续数据时预设预测效度检查

## 交付一致性

- [ ] 模型、参数表、报告、图表数字一致
- [ ] 版本号、日期、变更记录齐全
- [ ] 未解决问题有负责人、影响和处置决定
