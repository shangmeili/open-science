# 成本识别、测量与计价

成本工作分三步：识别资源项目、测量数量、赋予单位成本。必须分别记录数量与单价，避免结果无法迁移或复核。

## 视角与成本范围

| 视角 | 常见纳入内容 |
|---|---|
| 医保/支付方 | 支付范围内的药品、检查、治疗、住院等直接医疗成本 |
| 卫生体系 | 系统承担的全部直接医疗资源 |
| 全社会 | 直接医疗、直接非医疗、生产力损失等，按指南处理 |
| 医疗机构 | 机构实际承担的资源与成本 |
| 患者 | 自付医疗、交通照护、时间和生产力损失等 |

## 实务规则

- 优先使用与目标地区、年份和支付场景匹配的官方或权威单价。
- 资源使用与单价采用不同年份时，统一价格年并说明指数。
- 区分收费、支付价、采购价与经济成本；它们服务的视角不同。
- 纳入不良反应监测和处理成本。
- 排除只因临床试验而发生、常规诊疗不会发生的“试验引致成本”。
- 避免把同一影响既计入成本又计入效用或货币收益。
- 生产力损失方法（人力资本法、摩擦成本法等）需说明选择及敏感性。

## 贴现

中国 2020 指南建议时限超过 1 年时，对成本和健康产出采用相同的年贴现率 5%，并在 0%–8% 范围做敏感性分析。不同国家参考案例差异很大，例如 CDA-AMC 现行指南的参考案例为成本和结果年贴现 1.5%，并分析 0% 和 3%。所以贴现率必须来自目标决策环境。
