# 模型选择与结构

模型是对决策相关现实的有目的简化。模型类型由疾病过程、干预机制和决策问题决定，不由团队最熟悉的软件决定。

| 模型 | 适用情形 | 关键风险 |
|---|---|---|
| 决策树 | 短期、一次性事件、路径清楚 | 随时间复发或长期状态会迅速膨胀 |
| 队列 Markov | 有重复转移、状态可概括历史 | 无记忆假设；周期长度与半周期校正 |
| 隧道状态/半 Markov | 风险取决于进入状态后的时间 | 状态数量和透明度下降 |
| 分区生存模型 | 肿瘤中可直接用 PFS/OS 曲线分区 | 状态占比相关性、长期外推与机制解释弱 |
| 个体微观模拟 | 个体历史、竞争风险或异质性重要 | 计算量、随机误差和验证复杂 |
| 离散事件模拟 | 资源竞争、排队和事件时间重要 | 数据要求高，结构不透明风险 |
| 动态传播模型 | 疫苗、传染病、群体间感染反馈 | 接触结构与传播参数不确定性大 |

## 建模顺序

1. 画疾病自然史和当前治疗路径。
2. 标出干预影响的事件、成本与健康后果。
3. 明确状态/事件之间的因果关系和时间。
4. 再选择最简单且足够回答问题的模型。
5. 在填参数前让临床、患者/照护者和决策方验证概念模型。

## 周期与时限

周期应短到不会掩盖重要事件发生顺序；时限应长到捕捉方案间完整差异。需要时做半周期校正。不要用短期数据长度直接定义模型时限。

## 模型验证五层

- 表面效度：结构、假设和结果是否符合专业认知。
- 内部效度：公式、代码、单位和逻辑是否正确。
- 交叉效度：与独立模型比较。
- 外部效度：与模型外数据或真实结果比较。
- 预测效度：后续数据出现时检验预测。

中国 2020 指南明确要求所有模型至少做表面、内部和外部效度验证，并建议独立模型说明文件。
