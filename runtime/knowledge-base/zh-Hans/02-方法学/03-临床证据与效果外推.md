# 临床证据与效果外推

## 参数选择标准

按三个维度评价来源，而不是机械套“证据等级”：

- **适题性**：人群、对照、结局、场景和时间是否匹配决策问题。
- **可信度**：偏倚风险、测量质量、缺失和分析是否可靠。
- **一致性**：是否与模型中其他数据和疾病机制相容。

## 常见工作链

1. 系统或目标文献检索，建立证据地图。
2. 有头对头试验时优先直接相对效果。
3. 缺直接比较时，评估网络荟萃分析、间接比较或人群调整间接比较的可行性。
4. 将疗效转换为模型需要的风险、率、转移概率或生存函数。
5. 对超出观察期的效果做外推，并显式处理结构不确定性。

## 外推不是“把曲线拉长”

生存外推至少检查：比例风险假设、候选分布的统计拟合、曲线形状的临床合理性、外部长期数据、一般人群死亡上限、治疗效应是否衰减。基础分析和替代外推应由预先定义的规则选择，而不是挑选最有利结果。

## RWD 的作用

RWD 可用于描述目标人群、治疗路径、基线风险、资源使用、长期结局和实际效果。它不能因“样本量大”自动消除选择偏倚、信息偏倚和混杂。先写目标试验或因果问题，再选设计和方法。

## 可迁移性

临床相对效果可能比基线风险更可迁移；成本、资源使用、临床路径和效用价值集通常高度依赖地区。模型本土化必须逐项判断，不是只换币种和药价。
