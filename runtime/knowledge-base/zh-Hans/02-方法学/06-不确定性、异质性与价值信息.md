# 不确定性、异质性与价值信息

## 先分类，再选择工具

| 类型 | 含义 | 常用处理 |
|---|---|---|
| 参数不确定性 | 参数真实值未知 | PSA、确定性敏感性分析 |
| 结构不确定性 | 状态、关系或外推形式未知 | 替代模型/情景、模型平均 |
| 方法不确定性 | 视角、贴现率等方法选择 | 参考案例与非参考情景 |
| 异质性 | 不同人群的真实结果不同 | 预设亚组、交互与分层结果 |
| 随机变异 | 个体层面的偶然性 | 足够模拟次数、方差缩减 |

## 确定性分析

单因素分析用于发现结果对哪些输入敏感；变化范围应来自置信区间、数据范围或有依据的情景。旋风图是影响排序，不代表参数的重要性已被概率和相关性完整衡量。

## PSA

常见分布：概率/效用用 Beta，正成本用 Gamma 或对数正态，相对效应用对数尺度的正态，多项概率用 Dirichlet。相关参数应联合抽样。报告增量成本效果散点、CEAC 和不同阈值下的 NMB；不能只说“95% 模拟落在某象限”。

## 价值信息

- EVPI：完全消除不确定性最多值得付多少。
- EVPPI：消除某组参数不确定性的价值。
- EVSI：拟议研究带来的预期信息价值。
- ENBS：EVSI 减去研究成本后是否值得开展。

VOI 把“还不确定”转成“是否值得继续研究以及研究什么”，尤其适合附条件准入和生命周期证据计划。

## 结论写法

不要写“结果稳健”就结束。应写清：哪些假设会改变最优方案、在什么阈值范围内结论变化、哪个信息缺口的决策后果最大。
