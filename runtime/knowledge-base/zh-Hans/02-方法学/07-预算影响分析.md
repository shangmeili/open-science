# 预算影响分析

## 核心问题

BIA 从预算持有者角度估计：若准入新技术，未来若干预算期内净支出如何变化，能否承担。它与成本效果互补。

```text
年度预算影响 = 准入情景总成本 − 未准入情景总成本
```

## 建模顺序

1. 明确预算持有者、支付范围和年度周期。
2. 建目标人群漏斗：总人口 → 患病 → 诊断 → 符合条件 → 实际治疗 → 支付覆盖。
3. 定义未准入与准入情景中的治疗组合。
4. 逐年预测市场份额、替代、联合使用和市场扩张。
5. 计算药品、给药、监测、不良事件和其他疾病相关成本。
6. 报告逐年和累计净影响，并做关键情景与敏感性分析。

## 中国 2020 指南要点

- 通常采用预算持有者角度。
- 预测期一般为 3–5 年，逐年报告。
- 至少比较未准入与准入两个市场情景。
- 通常不贴现，因为每笔成本对应具体预算期。
- 成本范围严格服从预算持有者角度。
- 透明报告市场份额预测、数据和假设。

## 最常见失败

把流行病学患病人数直接当用药人数；市场份额加总不为 100%；忽略新药带来的诊断率或治疗率扩张；把 CEA 的长期平均成本直接搬入年度现金流；只给总额，不给逐年构成。
