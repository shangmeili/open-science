# 健康效用与 QALY 测量

效用通常以 1 表示完全健康、0 表示死亡；部分状态可低于 0。效用不是一般生活质量量表得分，只有偏好型测量或有效映射才可用于 QALY。

## 获取路径优先级

1. 在目标人群中使用通用偏好型量表直接测量，如 EQ-5D。
2. 使用与量表、国家价值集、疾病状态相匹配的研究数据。
3. 系统检索外部效用研究并评价适题性与一致性。
4. 在缺乏直接效用时使用经验证映射，并把映射误差纳入不确定性。
5. 直接偏好测量只在有充分理由时使用，并完整报告方法。

## 不能忽略的差异

- 量表版本、维度和价值集不同会给出不同效用。
- 患者自评、公众偏好和代理人报告回答不同问题。
- 暂时性不良事件可用效用下降幅度 × 持续时间建模。
- 照护者影响显著时，可作为补充分析；需避免与患者效用重复计算。
- 年龄、疾病阶段、治疗响应和事件史可能影响效用。

## 质量检查

检查效用是否与健康状态定义一致；是否出现重复扣减；基线效用和事件效用组合是否越界；死亡周期处理是否一致；价值集是否与目标地区匹配。
