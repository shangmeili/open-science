# 研究、证据与分析

关键词：文献搜索、全文下载、引用、参数、溯源、模型、Markov、决策树、PSA、研究与分析、学习库。

## 如何开始一项药物经济学研究？

在任务中说明研究对象、干预与对照、研究目的及已有材料。助手可帮助整理目标人群、分析视角、地区、时间范围和健康产出，再准备研究方案、概念模型和参数需求。

示例：

> 研究【药物 A】与【药物 B】在【人群】中的成本—效果。请先查找适应证、剂型和比较研究，给出带来源的基本信息，再用表单明确研究范围。

## 如何查找文献和公开数据？

明确检索主题、人群、干预、对照、结局、地区和时间范围。可使用证据检索、文献检索和生物医学数据库工具，并通过浏览器查找公开资料。

示例：

> 检索近五年与【研究问题】相关的文献和试验注册，整理标题、作者、年份、DOI 或 PMID、研究设计、主要结果和原始链接，保存到当前任务。

查找价格或其他参数时，补充地区、年份、规格和单位：

> 查找【药物及规格】在【地区、年份】公开可获得的采购价格，保存可下载的原始文件，并记录价格单位、发布日期、来源链接及换算过程。

## 全文如何下载和保存？

可以要求助手获取可下载的公开原文，保存到当前任务。参考文献库支持开放全文获取队列。要求结果清单中列出对应文献、原始链接、本地文件和下载情况，便于后续核查。

> 下载上述文献可获取的开放全文，保存到当前任务，并列出每篇文献的本地文件路径；未获得全文的条目也保留在清单中。

## 如何导入和去重参考文献？

添加 RIS、BibTeX 或 CSL-JSON 文献文件，使用“参考文献库”技能导入。可进一步要求去重、核对元数据及导出。

> 使用 $literature-review 导入这批 RIS 文件，合并重复文献，保留各条目的来源，并导出整理后的 RIS 和 BibTeX。

## 如何添加正文引用和参考文献表？

使用“引用与参考文献”技能，将正文需要引用的位置与本地文献库条目对应。可生成中文医学顺序编码、Vancouver 数字式或作者—年份格式。

> 使用 $citation-formatting，为这份报告补齐正文引用，并按 Vancouver 数字式整理参考文献表。

## 如何整理模型参数？

要求输出参数名称、数值、单位、适用人群、时间范围、来源、原文位置和换算过程。成本、效用、事件概率、相对效应和生存参数可分别使用对应技能处理。

> 整理模型所需参数，逐项对应到原始文献的表格或页码，并把已获取数值和仍待补充的参数分开列出。

## 有哪些分析功能？

| 工作 | 对应功能 |
| --- | --- |
| 短期路径比较 | 决策树 |
| 长期成本与健康结局 | 队列状态转移模型、半马尔可夫微观模拟 |
| PFS/OS 生存建模 | 分区生存模型、生存拟合、外推检查 |
| 财务与支付方影响 | 预算影响、动态预算影响 |
| 结果不确定性 | 单因素敏感性分析、概率敏感性分析、CEAC、CEAF、信息价值分析 |
| 间接比较与数据分析 | 网状 Meta 分析、锚定 MAIC、真实世界因果分析 |
| 参数预处理 | 成本标准化、健康效用、事件效用损失、背景死亡率、概率和效应转换 |
| 检查研究结果 | 模型验证、参考案例检查、输入溯源、统计与可重复性检查 |

具体工作可从“插件与技能”选择对应能力，或直接描述需求，让助手匹配合适的技能。

## “研究与分析”面板看什么？

打开任务的“研究与分析”面板，可查看本地证据库、证据综合、引用计划、分析计划、概念模型、输入来源、分析结果和待确认的研究选择。面板根据当前任务中的研究文件显示内容。

概念模型图可调整节点位置，并导出 SVG 和可编辑 GraphML。需要修改人群、方案或结构时，可在对话中说明修改要求。

## 如何查看某个数字的具体来源？

优先使用面板中的可点击数值、来源入口或关联文件，查看对应资料、提取记录和原文位置。也可直接要求：

> 请列出这个结果使用的具体输入，每项链接到原始文献、页码或表格，以及当前任务中的原文文件。

## 如何使用本地学习库？

在“研究与分析”的本地证据库区域，可以安装内置药物经济学学习库、添加知识库文件夹、添加单个资料或重新扫描资料。学习时说明主题、已有基础和时间安排。

> 根据本地学习资料，帮我学习成本—效用分析。先讲解一个主题，再用教学案例练习，并给出对应资料位置。
