# 常见问题

关键词：发送按钮、无法发送、离线、MCP 失败、Python 未找到、资料为空、结果过期、语言、文件、更新。

## 发送按钮点不了怎么办？

依次检查：输入框是否有内容；是否已选择可用模型；本地服务是否就绪；任务或项目是否仍在切换。未选模型时点击“选择模型”；服务异常时到“设置 → 本地服务”重新连接。助手正在处理时，新消息可以加入待发送队列。

## 模型列表为空怎么办？

先确认本地服务已连接，再打开“管理模型服务”。检查服务是否已添加、登录或密钥是否有效、自定义模型 ID 是否正确。清除搜索和收藏筛选后重新查看。

## 本地助手离线怎么办？

在设置中重新连接，或通过“使用准备情况”重新启动本地助手。若仍失败，检查网络代理设置和页面显示的错误，并导出诊断报告用于反馈。

## MCP 显示连接失败怎么办？

打开“设置 → 连接器”，查看失败的具体服务。检查所需密钥、本地启动命令或远程 URL；首次安装尚未完成时等待设置结束。重新启用后核对是否显示“已连接”。

## 未找到 Python 或 Jupyter 怎么办？

到“设置 → 本地服务”点击“安装本地环境”，或指定已有 Python 解释器。需要助手操作笔记本时，到“设置 → 连接器”设置并启用 Jupyter。下载失败时检查网络及软件包镜像设置。

## 找不到已下载的论文怎么办？

先打开下载时所在的任务，进入“任务文件”。也可以要求助手列出该批资料的本地路径和下载情况。对话中的网页链接表示来源位置；是否已保存，以本地文件和下载记录为准。

## 文件已经存在，本地证据库为什么仍显示零？

确认当前任务是否正确，然后在本地证据库区域添加相应资料或文件夹并重新扫描。任务文件和证据库收录情况可以分别查看。

## 为什么结果显示过期或需要重新计算？

当前研究计划、输入或证据发生变化后，需要更新计算结果。让助手检查变更，补齐输入，再重新运行相关分析。

> 检查哪些输入变化导致结果过期，列出需要重新运行的分析，然后更新结果。

## 为什么需要我确认研究内容？

某些选择会影响分析，例如研究人群、比较方案、时间范围、模型结构和关键假设。查看表单或研究与分析中的具体内容，选择、修改或补充后提交。看不到所引用的表格或资料时，可让助手先展示相应材料。

## 助手回答语言变化了怎么办？

可以直接说明：“本任务请始终使用中文回答，专业缩写和文献标题可保留原文。”界面语言在设置中调整。

## 如何查看已记住的操作权限？

打开“设置 → 隐私 → 已记住的权限”，查看当前项目记录，并按需要撤销。

## 表单选项都不适合怎么办？

使用自由填写入口说明实际情况，或在对话中说明希望修改的研究选择。可以要求助手根据补充内容重新组织问题。

## 能否使用其他模型服务？

可以。在“设置 → 模型”连接其他服务，或添加兼容 OpenAI/Anthropic 的自定义接口，然后选择模型。

## 如何检查应用更新？

在“设置 → 通用”的“应用更新”查看当前版本与发布信息。若显示“暂未开放在线更新”，通过提供给你的安装包更新。更新后可在关于区域核对版本。
