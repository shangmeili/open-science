# 产品与快速开始

关键词：AI4HEOR、入门、首次使用、研究工作台、导航、教学案例。

## AI4HEOR 是什么？

AI4HEOR 是面向药物经济学与卫生技术评估研究人员的 AI 科研桌面工作台。用户通过自然语言提出工作要求，完成研究问题梳理、文献与数据整理、模型分析、结果检查和研究成果制作。

研究资料、任务文件和分析结果在本地管理。对话可使用用户选择的在线模型或本地兼容模型服务。

## 第一次使用怎么开始？

1. 打开“设置”，查看“使用准备情况”，确认本地助手和项目文件夹可用。
2. 到“设置 → 模型”连接模型服务，并选择默认模型。
3. 点击“新建任务”，输入希望处理的工作；需要持续组织一项研究时，先新建项目，再在项目中创建任务。
4. 有现成资料时，使用输入框的附件按钮添加文件。
5. 按助手提出的具体问题补充信息，查看生成的文件、研究与分析面板和运行记录。

示例：

> 帮我开展一项药物经济学研究。研究对象是【药物和适应证】，准备比较【方案 A】与【方案 B】，用于【结果用途】。先检索基本信息，再用表单帮我明确研究范围。

## 界面各入口有什么作用？

| 入口 | 作用 |
| --- | --- |
| 新建任务 | 从一段新的自然语言请求开始工作 |
| 项目 | 集中组织同一研究的任务和资料 |
| 任务 | 查看独立任务及其对话 |
| 任务文件 | 浏览当前任务工作区中的文件，预览或用本机应用打开 |
| 插件与技能 | 查找研究能力，选择技能用于任务，管理相关能力 |
| 研究工作台 | 从学习、研究设计、证据检索、参数整理等常用工作开始 |
| 研究与分析 | 查看当前研究资料、分析计划、模型、参数来源、结果与待确认内容 |
| 运行记录 | 查看实际运行的状态、代码、输出和相关记录 |
| 设置 | 配置模型、本地环境、连接器、浏览器、计算、外观等 |

## 如何先熟悉软件？

在研究工作台选择“打开一个教学案例”。案例围绕成本—效用分析组织，包含研究问题、模型、输入、计算、敏感性分析和报告。运行后可以对照查看输入和输出。

也可以输入：

> 打开教学案例，带我依次查看研究问题、参数表、模型计算和结果，并告诉我每一步在界面哪里操作。

## 能生成哪些常用成果？

包括研究方案、证据表、参数表、模型图、分析结果、敏感性分析图、参考文献表、研究报告、汇报幻灯和复现材料。常用文件格式包括 Markdown、CSV、XLSX、DOCX、PDF、PPTX、SVG 和 GraphML。
