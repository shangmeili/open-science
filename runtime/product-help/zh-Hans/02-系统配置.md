# 系统配置

关键词：设置、模型、API、Ollama、Python、Jupyter、连接器、MCP、代理、镜像、浏览器、SSH、Modal、远程访问。

## 如何连接模型？

进入“设置 → 模型”，打开“管理模型服务”，选择服务商并按提示填写 API 密钥或完成登录。连接后，在模型列表中选择默认模型。可按名称、模型 ID 或服务商搜索，也可使用“收藏”和“最近使用”。

## 如何添加自定义模型接口？

在模型服务管理中选择“自定义模型接口”，填写：

| 字段 | 填写方法 |
| --- | --- |
| 名称 | 自己容易识别的名称，例如“单位模型服务” |
| 接口类型 | 按服务商说明选择“兼容 OpenAI”或“兼容 Anthropic” |
| 基础 URL | 服务商提供的接口基础地址 |
| API 密钥 | 使用该服务的密钥；无需认证的本地服务可留空 |
| 模型 ID | 填写服务实际提供的 ID；多个 ID 用逗号分隔 |

点击“添加模型接口”，然后在模型列表中选择相应模型。模型 ID 要使用服务商给出的准确值。

## 如何使用 Ollama？

先启动本机 Ollama 服务并准备所需模型。添加自定义接口时选择“兼容 OpenAI”，基础 URL 可填写 `http://127.0.0.1:11434/v1`，模型 ID 填写本机已有模型名称。保存后选择该模型。

## 本地服务如何配置？

“设置 → 本地服务”显示本地助手状态。正常使用时应用会管理该服务。若显示离线或错误，可重新连接，或在“使用准备情况”中选择“重新启动本地助手”。

网络连接可选择跟随系统、自定义代理地址或直连。自定义地址应填写本机实际可用的 HTTP 或 SOCKS5 代理。

软件包镜像可以设置 PyPI 索引和 Python 下载地址。留空使用默认下载源；安装环境下载较慢时，可填写自己可访问的镜像。

## 如何安装 Python 和 Jupyter？

在“设置 → 本地服务”的本地 Python 区域点击“安装本地环境”。应用会安装独立 Python、Jupyter 和常用科研依赖。安装完成后，该环境作为默认 Python 使用。

若已有 Python 环境，可以填写解释器完整路径并点击“使用此 Python”；点击“清除覆盖设置”恢复自动选择。

在“设置 → 连接器”中，Jupyter 的“设置并启用”用于让助手操作笔记本。应用内单元格运行与助手可使用同一套分析环境。

## 必须先安装分析环境吗？

普通对话、资料整理等工作可先连接模型开始。需要运行 Python 笔记本或相关分析时，再安装或指定 Python 环境。学习教学案例时，按页面提供的操作运行即可。

## 如何启用 MCP 连接器？

进入“设置 → 连接器”，找到需要的工具并点击“启用”。要求密钥的工具先填写密钥，再启用。查看状态是否为“已连接”。

自行添加 MCP 时，填写名称，并选择本地命令或远程 URL，点击“添加服务器”。当前可调用的工具以连接状态和服务提供的能力为准。

常用工具：文献检索、生物医学数据库、HEOR 证据检索、Jupyter 和浏览器控制。完整说明见插件与技能目录。

## 如何配置浏览器操作？

进入“设置 → 浏览器”：

1. 选择独立浏览器或可用的 Chrome 登录身份。
2. 选择是否显示浏览器窗口。
3. 根据需要选择能力范围，填写允许访问的域名。
4. 应用更改并启用浏览器控制。

首次使用独立浏览器时可能需要下载。随后可在任务中要求助手打开网页、读取页面、点击或填写表单。

## 如何使用远程计算？

进入“设置 → 计算”，在远程计算区域添加 `user@host`，或选择现有 SSH 配置。检测成功后，可查看计算资源及 Slurm 队列，并通过对话提交、查看或取消任务。

## 如何从另一台设备访问？

进入“设置 → 远程访问”，启用后选择可访问范围及“只读”或“完全访问”。在另一台设备的浏览器打开所示地址，并输入访问令牌。重新生成令牌后，现有客户端需要使用新令牌连接。

## 如何调整外观和语言？

“设置 → 外观”提供浅色、暖色、深色主题及缩放。语言选项用于切换界面语言。缩放快捷键以界面提示为准，macOS 使用 Command，Windows 通常使用 Ctrl。

## 如何查看权限和反馈问题？

在“设置 → 隐私”查看当前项目“已记住的权限”，可逐项撤销。对话框的操作确认菜单可选择“重要操作先确认”或“全部允许”。

反馈故障时，可在设置中的“问题诊断”导出诊断报告。联系邮箱：shangmei.li@altolix.com。
