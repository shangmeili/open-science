# 插件与技能目录

关键词：Skill、技能选择、插件、MCP、文献、模型、报告、PPT、Excel。

## 如何选择？

自然语言说明任务即可，也可在“插件与技能”中查找名称并点击使用。在对话框输入 `$` 选择技能，随后补充具体工作要求。下表中的 ID 可用于准确识别技能。

技能用于组织和完成某类工作；连接器用于访问数据库、浏览器或计算工具。需要外部工具时，先在设置中启用对应连接器。

## 如何增加自己的技能？

描述希望重复使用的工作步骤、所需输入和输出，使用“AI4HEOR Skill 创建”整理候选技能。查看候选内容，按界面的确认流程启用后，可在后续任务中使用。

示例：

> 把这次参数整理流程做成一个技能：输入研究问题和文献，输出含数值、单位、页码、换算和缺失项的参数表，供我检查后启用。
